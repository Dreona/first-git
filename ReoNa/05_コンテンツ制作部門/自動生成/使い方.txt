ひよりん便(Discordへのプラン別自動投稿)の使い方
作成: 2026-10-05 クラウド側のClaude
※実際のウェブフックURLがないため、本物のDiscordへの送信テストはしていません(送る直前までの動きは確認済み)。
  最初の1回は、テスト用の部屋で試してください(下の「はじめての試し方」)。

================================================================
■ この道具がやること
================================================================
・プラン別フォルダ(gold / silver / bronze)の画像とお知らせ文を、それぞれの部屋へ送る。
・送る前に、画像の生成情報(PNGインフォ・EXIF)を自動で消す。
  (元の画像はそのまま。消したコピーを送ります。モザイクは今まで通り社長が入れてください)
・10枚ずつに分けて送る(Discordは1回10枚まで)。合計が大きいときは、さらに分ける。
・Goldは1つのZIPにまとめる。大きすぎるときは「_1of3.zip」のように、それぞれ単独で開けるZIPに分ける。
・途中で止まっても、次に動かすと続きから送る(同じ画像を二重に送らない)。
・使えるのは PNG と JPG だけ。それ以外(webpなど)は送らずに注意を出します。
・1枚で20MBを超える画像はエラーにして、1枚も送りません(先に全部チェックしてから送ります)。

================================================================
■ 最初の準備(1回だけ)
================================================================
1. パソコンにPythonが入っているか確認
   スタートメニューで「cmd」と入れて開き、 python --version と入れてEnter。
   「Python 3.○○」と出ればOK。出なければ Microsoft Store で「Python 3.12」を入れる(無料)。
2. このフォルダ(05_コンテンツ制作部門/自動生成)で、discord_send.py を一度動かす:
   フォルダを開いて、アドレス欄に cmd と入れてEnter → 出てきた黒い画面で
       python discord_send.py 予約
   と入れてEnter。「設定ファイルを作りました」と出て、discord_webhooks.txt ができます。
3. discord_webhooks.txt をメモ帳で開き、gold= silver= bronze= の右にウェブフックURLを貼って保存。
   (URLの作り方は 02_Patreon部隊/成果物/2026-10-05_Discord準備手順_社長用.txt の手順5)
   Bronze休止中は bronze= を空のままにすれば、Bronzeには送りません。

================================================================
■ 毎回やること
================================================================
1. このフォルダの中の「予約」フォルダに、送る日時の名前でフォルダを作る。
     例) 予約\2026-11-01_2100   ← 2026年11月1日 21時00分に送る
2. その中に gold / silver / bronze のフォルダを作り、画像を入れる。
3. お知らせ文.txt を入れる(UTF-8で保存。メモ帳なら普通に保存すればOK)。
   ・プランごとに変えたいとき: gold\お知らせ文.txt のように各フォルダに入れる。
   ・全プラン同じでいいとき: 2026-11-01_2100\お知らせ文.txt に1つだけ置く。
4. あとは予約の時刻に自動で送られます(下の「予約の設定」をしておく)。
   すぐ送りたいときは、黒い画面で:
       python discord_send.py 予約\2026-11-01_2100

送る前に中身を確かめたいとき(送らずに表示だけ):
       python discord_send.py 予約\2026-11-01_2100 --dry-run

送った結果は、各フォルダの 送信記録.json と、このフォルダの 送信ログ.txt に残ります。

================================================================
■ 予約の設定(Windowsのタスク スケジューラ・1回だけ)
================================================================
1. スタートメニューで「タスク スケジューラ」を開く。
2. 右側の「基本タスクの作成」→ 名前「ひよりん便」→ 次へ。
3. トリガー:「毎日」→ 開始時刻は今日の 0:00 → 次へ。
4. 操作:「プログラムの開始」→「参照」でこのフォルダの 予約送信.bat を選ぶ → 完了。
5. できた「ひよりん便」を右クリック →「プロパティ」→「トリガー」タブ →「編集」で
   「繰り返し間隔」にチェック → 15分 / 継続時間「1日」→ OK。
6. 「条件」タブで「コンピューターをAC電源で使用している場合のみ…」のチェックを外す(ノートPCの場合)。
→ 15分おきに「予約」フォルダを見て、時刻を過ぎていてまだ送っていないものだけ送ります。
※パソコンの電源が切れていると送られません。電源を入れた後の最初の15分で、遅れて送られます。

================================================================
■ はじめての試し方(おすすめ)
================================================================
1. Discordに自分だけが見える「テスト部屋」を作り、そこのウェブフックURLを gold= に貼る。
2. 予約\テスト のような日時でない名前のフォルダに gold フォルダと画像2〜3枚を入れる。
   (日時の名前でないフォルダは自動では送られません)
3. python discord_send.py 予約\テスト で送り、テスト部屋に届くか、画像の生成情報が消えているか確認。
4. うまくいったら、gold= を本物のGold部屋のURLに書き換える。

================================================================
■ 困ったとき
================================================================
・「ウェブフックURLが無効です」→ 部屋のウェブフックが消えています。作り直して貼り直す。
・「大きすぎます」→ その画像をJPGにするか、小さくして入れ直す。
・「インターネットにつながりません」→ ネットを確認して、もう一度動かす(続きから送ります)。
・送り直したい → そのフォルダの 送信記録.json を消すと、最初から送り直します。
・エラーの内容は 送信ログ.txt に出ています。分からなければ、その部分をClaudeに見せてください
  (ウェブフックURLは見せないでください。ログにはURLは出ません)。
